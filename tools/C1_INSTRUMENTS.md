# C1 仪器能力面声明

时间：2026-11-07

结论：

```text
tools/c1_self_report.py
tools/c1_pressure.py
```

**不登记为常开能力，不进入 PAI_* 开关面。**

理由：

1. 它们是人工跑一次的测试仪器，不是常驻能力。
2. 没有默认执行路径；只有显式命令才会调模型。
3. 没有自动调度、没有后台循环、没有开机启动。
4. 给它们造一个 `PAI_C1_*` 开关，等于把“人工仪器”伪装成“常开能力”，是假登记。
5. `tools/check_capability.py` 的扫描面只有 `pai/`（ADR-079），这是定稿，不是疏漏。

边界：

```text
不接日常对话
不写库
不常开
不自动跑
只在人工命令下调用模型
```

如果以后要把 C1 变成常开能力：

```text
先把仪器逻辑上收到 pai/
再按 CAPABILITY 契约登记
再给真实开关与守卫
```

在那之前：

```text
F9 选择：3
C1 工具不属能力面
```
