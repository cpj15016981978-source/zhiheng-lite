# 定时任务（scheduled-tasks）

## 何时使用
- 用户说"每天 21:30 写日报""每天早上提醒我""定时做 X"。
- 不用于只做一次的任务（那种走规划循环或对话）。

## 怎么做
1. 调 `POST /api/task`，传 `{"time": "HH:MM", "prompt": "到点做什么"}`（`add_task()` 会校验时间格式是 HH:MM，存进 `tasks` 表，并用 `schedule` 注册每天执行）。
2. 到点后 `run_scheduled_task()` 自动执行：调一次模型（`run_ai_agent()`），结果记进记忆，并更新 `last_run`。
3. 任务存在本地数据库，重启后自动恢复（`load_tasks()`）；电脑关机时任务不会跑，开机后恢复。
4. 任务名默认取提示词前 20 字；重名任务按名字更新 `last_run`，不要重复建同名任务。
5. 每次执行都要调一次模型，会消耗免费额度；提醒用户别设太频繁。

## 验收标准
- 时间格式不对时明确报错（"时间格式不对，用 HH:MM"），不建任务。
- 建好的任务出现在任务列表里（`GET /api/tasks`）。
- 到点执行后结果记进记忆，`last_run` 有更新时间。
- 重启后任务还在，不用重新建。
