# 对话（chat）

## 何时使用
- 用户问一句话就能答完的问题：聊天、解释概念、写一段代码、做一次分析。
- 没有别的技能匹配时默认用这个。
- 不用于需要多步完成的任务（那种走规划循环）、定时任务、文件审批、自我检查。

## 怎么做
1. 调 `POST /api/chat`，传 `{"prompt": "内容"}`（`run_ai_agent()` 会带上最近 5 条记忆调模型）。
2. 回答里如果有 Python 代码块（```python），会自动存到 `scripts/` 目录（`save_code_blocks()`），只存不执行。
3. 用户的话和 AI 的回答都会记进记忆（`save_memory()`），方便以后搜到。
4. 回答要直接、具体；不确定的地方说"不确定"，不要编数字、编结论。
5. 如果用户的要求其实需要多步完成（例如"写一份周报保存成文件"），提醒他去任务页用规划循环，不要在对话里硬做。

## 验收标准
- 回答直接对应用户的问题，不跑题。
- 代码块正确保存到 `scripts/`，文件名带时间戳。
- 对话已记进记忆（`memories` 表里有 user 和 ai 两条）。
- 不确定的内容明确标出，不编造。
