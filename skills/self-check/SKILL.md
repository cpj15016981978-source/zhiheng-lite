# 自我检查（self-check）

## 何时使用
- 一个任务的全部步骤做完后，用户说"自我检查""检查一下结果""审一遍"。
- 只在任务完成后用，不要在每一步后都检查。
- 不用于改写结果——只检查、只报告。

## 怎么做
1. 调 `POST /api/plan/reflect`，传 `{"plan_id": id}`（`reflect_plan()` 会把全部步骤的结果拼起来调一次模型）。
2. 模型以质检员的身份检查：有没有错漏、前后矛盾、没做完的地方；结论是"通过"，或者列出要改的地方（每条一句话）。
3. 检查只做一次，不反复检查；检查结果记进记忆（`save_memory(..., kind="task")`），不直接改步骤结果。
4. 如果检查出问题，把问题列出来交给用户决定怎么改，不要擅自重做。

## 验收标准
- 检查覆盖全部步骤的结果，不只看最后一步。
- 结论明确：要么"通过"，要么列出具体要改的地方。
- 检查不改写步骤结果原文（`plan_steps.result` 不动）。
- 检查结果已记进记忆，可搜索到。
